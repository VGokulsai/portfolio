# portfolio

My site. One hand-written HTML file, no framework and no build step.

The design system is the one measured from resend.com in `resend-copy`: the
type scale, the tracking that tightens as size grows, the 96px/24px spacing
rhythm, one easing curve. The palette and every word are mine.

Open `index.html`.
